# P8 — Free Android Launch (2 weeks)

Publishing is an **owner action**. Agents prepare; the owner presses the buttons.

## Tasks

| ID | Task | Lane |
|---|---|---|
| P8-01 | Final brand, application ID, icon (name availability checked) | Owner, then Platform applies |
| P8-02 | Store assets: screenshots from the Screen Gallery, descriptions without medical claims | UI + owner |
| P8-03 | Support email, privacy policy URL, Pakistan legal review → `DECISIONS.md` | Owner |
| P8-04 | Consent-gated analytics events (blueprint §11), no health values | Platform + Integration |
| P8-05 | Data safety form and health apps declaration matching SDK behaviour | Owner, Platform drafts |
| P8-06 | Signed release (owner-controlled key), `RELEASE_CHECKLIST.md` complete | Platform + owner |
| P8-07 | Internal → closed → staged production 10% → 50% → 100% | Owner |

## Exit criteria (blueprint)

- [ ] Core flows work with network blocked
- [ ] Nutrition review complete
- [ ] Data safety form matches SDK behaviour
- [ ] Signed release and checklist ready
- [ ] Crash-free ≥ 99.5% at each rollout step
