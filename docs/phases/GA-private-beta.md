# Gate A — Private Beta (3 weeks, owner-led)

## Tasks

- [ ] GA-01 Play Console account (owner decision: personal vs organisation) and signing ownership. Owner.
- [ ] GA-02 Closed testing track with ≥ 30 testers (covers Play's 12 testers / 14 days rule). Owner.
- [ ] GA-03 Consent-gated crash reporting enabled for beta (Platform).
- [ ] GA-04 Weekly beta report: logging retention, crashes, data-loss reports, top feedback. Agent may compile from exports.
- [ ] GA-05 Nutritionist sign-off on data and TargetPolicy values. Owner.

## Pass criteria

- [ ] ≥ 40% of testers still logging in week 3
- [ ] No data-loss bugs
- [ ] Nutritionist sign-off on data and policy
