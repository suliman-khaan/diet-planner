# Global Diet Planner

Offline-first meal planner built on the food people actually eat. First market: Pakistan. First platform: Android (Flutter).

This is the pure release branch for the production application and APK builds. Active development, architecture documentation, design specifications, and agent workflows live on the [`development`](../../tree/development) branch.

## Layout

```text
apps/mobile/            Flutter app
content/pakistan/       Food pack source data
contracts/              Food-pack schema (OpenAPI added in v1.5)
tools/                  Food-pack validator CLI
.github/workflows/      CI
```

## Setup

Flutter, Dart, JDK and Android SDK are required for `apps/mobile`. Full setup steps will be added once the Flutter project skeleton is in place.
