# AGENTS.md

All agent and contributor rules live in the `.agent/` folder. Read in this order:

1. `.agent/AGENTS.md` — working agreement
2. `.agent/rules/` — all rule files (collaboration first)
3. `.agent/lanes/<your lane>.md` — the only paths you may edit
4. `docs/WORKBOARD.md` — claim a task; details in `docs/phases/`
